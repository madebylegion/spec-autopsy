# Implementation Plan

Each task is small enough for one call and ends with its own tests. Tests mirror `src/` in `tests/indexer/`, `tests/linker/` and `tests/report/`; fixtures are in `tests/fixtures/`. Run tests with `npx vitest --run` and type check with `npx tsc --noEmit`. No new dependencies. Never change THRESHOLD or any `expected.json` (the one exception: task 5 may append an add-only entry). Do not open or edit `tests/fixtures/heldout/`, `tests/fixtures/blind3/` or `tests/fixtures/blind4/` (the one exception: tasks 4 and 5 link the held-out fixture in a new test, read-only). Do not edit the assertions of an existing test; if one fails because of the new behavior, name it in design.md ("Existing tests that may fail") and in the reply, and stop for the human to decide. Hard-code no fixture name in `src/`.

# Implementation Plan

Each task is small enough for one call and ends with its own tests. New tests go in new files under `tests/ui/` (the last task extends `tests/report-and-morgue/style-rules.test.ts`). Run tests with `npx vitest --run` and type check with `npm run typecheck`. Do not edit any existing test file to make it pass (the one exception is appending cases to `style-rules.test.ts` in task 4, without changing an existing case); if an existing test fails because of the new behaviour, leave it, and say which test and why in the reply. Do not touch `src/linker`, `src/indexer`, `src/parser` or `src/report`, and do not change `package.json`. Every colour is a token. No gradient function, no new font, no new dependency. Do not run dev-server or watch commands. The orchestrator runs `npm run morgue` and takes the screenshots after a task, using the manual checklist at the end of design.md.
